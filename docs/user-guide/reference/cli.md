# CLI reference

This page will be generated from the command-line interface once every command exists, so it cannot drift from the code.

Until then the built-in help is authoritative:

```
thumbforge --help
thumbforge <command> --help
thumbforge <command> <subcommand> --help
```

Global options (`--config`, `--data-dir`, `--json`, `-v`/`-vv`, `--quiet`, `--no-color`, `--version`) go before the command name.

## Exit codes

Exit codes are defined in [`PLAN.md` §5.1](https://github.com/khiladisngh/thumbforge/blob/main/PLAN.md#51-exit-codes) and are the same for every command.
